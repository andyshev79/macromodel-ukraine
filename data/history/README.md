# История реперов: покрытие

Собрано `scripts/fetch_history.py`. Квартал в колонках, код ряда в строках. Полный список с методами в `catalog.csv`.

## Конвенции

- Реальный ВВП в средних ценах 2021 года: номинал 2021 по кварталам, остальные кварталы сцеплены через официальный реальный рост к тому же кварталу прошлого года. Годовой рост совпадает с официальным с точностью до сцепления; квартал к кварталу сравнивать нельзя (сезонность наследуется от 2021), поэтому и дефлятор сравнивать только г/г.
- Номинальный ВВП по годам совпадает с данными Всемирного банка (проверено 2015–2025).
- Инфляция: % г/г на последний месяц квартала (как в отчётах НБУ).
- Ставки по кредитам и депозитам: новые операции в гривне, средневзвешенные по объёмам за квартал.
- Бюджет: государственный бюджет, накопленные с начала года данные Казначейства переведены в кварталы по месяцам конца квартала.

## Длинная история (`long/`)

Для оценки уравнений: те же рецепты с 2005 года (`long/anchors_q.csv`, `long/series_q.csv`, `long/catalog_q.csv`) и годовая таблица `long/annual_y.csv` 2005–2025 с каталогом `long/catalog_y.csv` (там же `history_long.xlsx`).

Годовая строка = кварталы, свёрнутые по правилу репера (SUM / AVG / END), где есть все четыре квартала; годы раньше квартальных данных берутся из годового источника, и в каталоге написано, с какого года начинается свёртка:

| Ряд | Кварталы с | Годы до этого |
|---|---|---|
| GDP_NOM, GDP_REAL, DEFL | 2010–2011 (API) | Госстат через НБУ `macro/GDP_y.xlsx`: номинал, индекс физобъёма; реальный ВВП сцеплен назад в ценах 2021 |
| GDP_REAL_YOY, DEFL_YOY | — | Официальные годовые индексы Госстата за все годы |
| CPI_YOY | 2007 | 2005–2006: среднегодовой ИПЦ ВБ |
| PPI_YOY, PPI_METAL_YOY | 2007 (до 2013 файл НБУ `PPI_q` и MacroStat) | — |
| LOAN_RATE, DEP_RATE | 2010 | ВБ: средние ставки по всем кредитам/депозитам (уровень выше, чем по новым гривневым) |
| EXP_USD, IMP_USD, TRADE_BAL | 2010 | ВБ, платёжный баланс (BX/BM.GSR.GNFS.CD) |
| GFCF | 2010 | ВБ, NE.GDI.FTOT.CN |
| WAGE_NOM | 2010 (НБУ `Wages_m`) | НБУ `Wages_y` (Госстат) |
| FX, NBU_RATE, RES_USD, M0, M3, EMPL, UNEMP | 2005 | — |

Только годовые ряды: реальный рост компонентов ВВП и отраслей по ВБ (`WB_*`), ИПЦ среднегодовой, кредит частному сектору, % ВВП (с 2008), производство в натуре по Госстату (`PROD_*`: уголь, газ, чугун, электроэнергия до 2020; сталь и прокат только до 2010, дальше конфиденциально).

Новые квартальные ряды (есть и в `series_q.csv` с 2015):
- `IND_*_YOY`: промпроизводство по 12 отраслям, вкл. металлургию `IND_C8_YOY` (КВЭД 24–25), с 2013; общий индекс `IND_PROD_YOY` с 2010 (2010–2012 из MacroStat);
- `PPI_METAL_YOY`, `PPI_MINING_YOY`: цены производителей, с 2007;
- `CPI_<группа>_YOY`: ИПЦ по группам из API с 2007 (продукты, алкоголь и табак, ЖКУ, здравоохранение, транспорт) и по позициям из MacroStat с 2011 (электроэнергия, газ, отопление, вода, топливо);
- `EXPG_*_USD`, `IMPG_*_USD`: товарный экспорт и импорт по 8 группам (агро, минеральные, химия, древесина, промтовары, металлы, машины, прочее), НБУ `Trade_m.xlsx`, с 2010;
- `PX_*_USD`: экспортные цены FOB Черное море (пшеница, ячмень, подсолнечное масло, соя), MacroStat AGROTrends, с 2010;
- `CB_*`: сводный бюджет по месяцам из MacroStat (лист Budget) с 2011: налоги (НДФЛ, налог на прибыль, НДС, акцизы), гранты, расходы по функциям (оборона, порядок и безопасность, `CB_DEFSEC` = их сумма) и по экономической классификации, финансирование;
- `STAFF_EMPL`: среднеучётная численность штатных работников (Госстат, НБУ `Number_m.xlsx`) с 2010: сигнал занятости после 2021, нет 2023 года.

Чего нет: квартального ВВП до 2010; ежемесячной выплавки стали (сайты GMK Center и worldsteel закрыты сетью окружения, Госстат засекретил сталь после 2010); ОРС после 2021 (Госстат его не возобновил); инфляционных ожиданий НБУ (файл не найден на сайте НБУ по известным адресам).

## Ручные источники

`MacroStat.xlsx` (экспорт Google-таблицы Андрея) кладётся в `data/raw/manual/` и в репозиторий не попадает. Из него берутся: квартальные зарплаты 2022–2024, перевезения грузов, зарегистрированная безработица, валовое внешнее финансирование, платежи по госдолгу и годовой график платежей до 2050 (`debt_schedule_y.csv`). Без файла эти ряды пустые, остальное собирается как обычно.

Из MacroStat также берутся: ИПЦ по позициям (лист CPI), индекс промпроизводства 2010–2012 (SectorIndexes M), экспортные цены (AGROTrends), сводный бюджет (Budget). Скрытые столбцы читаются как обычные.

Замечания по самому MacroStat:
- лист Salary: квартальные зарплаты 2010–2012 не совпадают с Госстатом (2011 повторяет 2013, 2012 около 2 000 грн), в загрузку идут только с 2022;
- лист CPI: у электроэнергии, газа, отопления и воды пусты сентябрь–декабрь 2023 и октябрь 2024 (у топлива июль 2024), поэтому годовые изменения этих позиций за 2023Q3–2025Q3 пустые;
- лист Help: сумма месяцев 2024 года на 1 000 млн USD больше колонки «2024» (вероятно, ERA в декабре), а за 2025 на ~7 350 млн USD больше колонки «2025»; в загрузку идёт сумма месяцев;
- лист Debt, ноябрь 2024: обслуживание внешнего долга 45 607 вместо ~45,6 млрд грн; внешние платежи считаются как «всего минус внутренний долг», разбивка за такие месяцы пустая;
- лист Debt, август 2024: 612 млрд грн погашения внешнего долга (реструктуризация еврооблигаций) попадает в DEBT_PAY_EXT_UAH за 2024Q3.
