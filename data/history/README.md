# История реперов: покрытие

Собрано `scripts/fetch_history.py`. Квартал в колонках, код ряда в строках. Полный список с методами в `catalog.csv`.

## Конвенции

- Реальный ВВП в средних ценах 2021 года: номинал 2021 по кварталам, остальные кварталы сцеплены через официальный реальный рост к тому же кварталу прошлого года. Годовой рост совпадает с официальным с точностью до сцепления; квартал к кварталу сравнивать нельзя (сезонность наследуется от 2021), поэтому и дефлятор сравнивать только г/г.
- Номинальный ВВП по годам совпадает с данными Всемирного банка (проверено 2015–2025).
- Инфляция: % г/г на последний месяц квартала (как в отчётах НБУ).
- Ставки по кредитам и депозитам: новые операции в гривне, средневзвешенные по объёмам за квартал.
- Бюджет: государственный бюджет, накопленные с начала года данные Казначейства переведены в кварталы по месяцам конца квартала.

## Пробелы

| Ряд | Что не так | Что делать |
|---|---|---|
| EMPL, UNEMP | Обследование рабочей силы прекращено после 2021Q4 | Оценка блока B4 (зарплатный фонд, ЕСВ, данные служб занятости), внешние оценки НБУ |
| WAGE_NOM | API НБУ не содержит 2022–2023 и 2024Q3–Q4 | Закрыто квартальными данными Госстата из MacroStat (лист Salary) |
| POP | Оценка Всемирного банка на всю страну, годовая | Заменить сценарной оценкой для подконтрольной территории |
| CFC | Только до 2021, годовые оценки ВБ | Норма выбытия от ВНОК в блоке B8 |
| ELEC_CONS | Годовые оценки ВБ до 2024, вся страна | Данные Укрэнерго (сайт ua.energy закрыт в окружении) |
| FREIGHT | В MacroStat есть перевезения грузов в млн т (не т·км), с 2018 | Единица репера изменена на млн т; т·км и 2015–2017 добрать из Госстата |
| BUDGET_EXP | Нет 2023Q3–Q4 (в API пропущен сентябрь 2023) | Добрать из отчёта Казначейства |
| BUDGET_REV | После 2024Q1 API не публикует доходы | Считается тождеством: расходы + кредитование − финансирование |
| FIN_RECEIVED_USD | Чистое привлечение из платёжного баланса | Валовое по донорам: EXT_FIN_GROSS_USD из MacroStat (лист Help), 2022–2023 только годовые суммы |
| FIN_NEED_USD, FIN_GAP_USD | Расчётные | Блок B6: дефицит, платежи по долгу (DEBT_PAY_*, debt_schedule_y.csv до 2050) |

## Ручные источники

`MacroStat.xlsx` (экспорт Google-таблицы Андрея) кладётся в `data/raw/manual/` и в репозиторий не попадает. Из него берутся: квартальные зарплаты 2022–2024, перевезения грузов, зарегистрированная безработица, валовое внешнее финансирование, платежи по госдолгу и годовой график платежей до 2050 (`debt_schedule_y.csv`). Без файла эти ряды пустые, остальное собирается как обычно.

Замечания по самому MacroStat:
- лист Help: сумма месяцев 2024 года на 1 000 млн USD больше колонки «2024» (вероятно, ERA в декабре), а за 2025 на ~7 350 млн USD больше колонки «2025»; в загрузку идёт сумма месяцев;
- лист Debt, ноябрь 2024: обслуживание внешнего долга 45 607 вместо ~45,6 млрд грн; внешние платежи считаются как «всего минус внутренний долг», разбивка за такие месяцы пустая;
- лист Debt, август 2024: 612 млрд грн погашения внешнего долга (реструктуризация еврооблигаций) попадает в DEBT_PAY_EXT_UAH за 2024Q3.
