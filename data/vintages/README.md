# Версии прогнозов

`vintages.csv` — все сохранённые прогоны модели в длинном формате (`macromodel/vintages.py`):
ввод (SCENARIOS), результаты (ANNUAL), проверки (CHECKS) и выводы. Та же таблица лежит на листе VINTAGES.

Папка на каждую версию (`ГГГГ-ММ-ДД_сценарий_vN/`) хранит снимок значений листа, из которого она собрана.
Новая версия: снять значения листа в такую папку и запустить
`python -m sheet.vintage_payload <папка> <первая свободная строка VINTAGES>`.

Ошибки прогнозов по закрытым годам: `from macromodel.vintages import errors; errors()`.
