# Макромодель Украины

Объяснимая эконометрическая модель ключевых показателей Украины на 2–3 года: квартальная частота, годовая агрегация, подконтрольная территория.

Основная часть модели (допущения, сценарии, формулы прогноза, проверки) живёт в Google-таблице. Этот репозиторий делает то, что неудобно считать формулами:

- `macromodel/loaders/` загружает данные: `nbu_api.py` (открытый API НБУ, в том числе ряды Госстата и Казначейства), `worldbank.py`, `minfin_index.py` (госдолг), `nbu.py` (официальный курс и файлы НБУ);
- `macromodel/history.py` собирает квартальную историю реперов и вспомогательных рядов; каждый ряд описан рецептом (источник, способ расчёта);
- `macromodel/aggregate.py` приводит ряды к кварталам и годам;
- `macromodel/anchors.py` хранит список реперных переменных, тот же, что на листах DICT и ANCHORS;
- `sheet/` собирает каркас таблицы (`python sheet/build_frame.py`);
- `docs/model_logic.md` описывает правила модели: что связывает блоки и почему выбрано именно так.

## Запуск

```bash
pip install -r requirements.txt
python scripts/fetch_history.py          # ~7 минут при пустом кэше, дальше ~1 минута
python scripts/fetch_history.py --offline  # пересобрать из кэша data/raw
pytest
```

Результат в `data/history/`: `anchors_q.csv` (реперы по кварталам), `series_q.csv` (вспомогательные ряды), `catalog.csv` (источник, метод, первый и последний квартал каждого ряда) и `history.xlsx` с теми же тремя таблицами для импорта в Google-таблицу. Что есть и чего нет, описано в `data/history/README.md`.

### Пересчёт модели после новых данных

```bash
python scripts/recalc.py           # или --fetch: сначала скачать историю
```

Собирает в `data/recalc/payload.json` всё, что зависит от данных: факт в ANCHORS (2015Q1–2026Q2, только ряды с данными; формулы и оценки блоков не трогает), коэффициенты COEFS (годовые и квартальные оценки, шоки, уравнение зарплаты), тексты уравнений на листах блоков и лист MODEL_QUALITY. Печатает, какие ячейки изменились с прошлого запуска (`data/recalc/last.json`). SCENARIOS и ручные значения не перезаписываются. После записи в таблицу обновить SUMMARY по трём сценариям.

## Источники

mof.gov.ua блокирует облачные адреса, а сайт МВФ закрыт сетевой политикой окружения. Поэтому данные Минфина берутся из API НБУ, а госдолг с index.minfin.com.ua. История модели строится из копии данных Госстата в API НБУ; сам Госстат (stat.gov.ua, открытый SDMX API за страницей explorer) загружается отдельно, чтобы ловить пересмотры и новые кварталы.

### Госстат напрямую

```bash
python scripts/fetch_ukrstat.py                 # ~2 минуты, все наборы
python scripts/fetch_ukrstat.py --sets cpi_m    # один набор
python scripts/fetch_ukrstat.py --check-only    # только сверка по уже скачанным снимкам
```

Наборы перечислены в `macromodel/loaders/ukrstat_sdmx.py` (`SETS`): ВВП квартальный, ИПЦ и базовая инфляция, ИЦП, промышленность, строительство и цены в строительстве, розница, сельское хозяйство, зарплаты и занятые (месяц, квартал), капинвестиции, грузы, цены на жильё и услуги, внешняя торговля. Госстат пересматривает прошлые значения, поэтому каждый запуск берёт полную историю, а не только новые месяцы, и сравнивает её с прошлым снимком. Результат в `data/ukrstat/`:

- `<набор>.csv.gz`: текущий снимок (ряд, период, значение, дата выпуска);
- `revisions.csv`: журнал всех изменённых и удалённых значений (дата загрузки, старое, новое, %); дописывается, не перезаписывается;
- `status.csv`: последний период, дата выпуска и следующего выпуска, сколько новых значений и пересмотров дал запуск;
- `crosscheck.csv`: сверка ключевых рядов (ВВП, ИПЦ, базовая, ИЦП, зарплата, промышленность, розница, стройка) с историей модели и кварталы, которые у Госстата уже есть, а в истории ещё нет.

`python scripts/recalc.py --fetch` запускает загрузку Госстата сам, после истории.

```text
stat.gov.ua/sdmx             Госстат: снимки наборов, журнал пересмотров, сверка
bank.gov.ua/NBUStatService   ВВП, цены, зарплаты, ОРС, бюджет, платёжный баланс, резервы, внешний долг, деньги, ставки
bank.gov.ua/NBU_Exchange     официальный курс
api.worldbank.org            население, потребление капитала, электроэнергия (годовые, оценки)
index.minfin.com.ua          государственный и гарантированный долг на конец месяца
```
